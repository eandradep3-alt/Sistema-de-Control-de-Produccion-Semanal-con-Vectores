# -Sistema-de-Control-de-Producci-n-Semanal-con-Vectores

## 1. Descripción del Caso

Una empresa embotelladora desea analizar la producción semanal de una de sus plantas.
Para ello se utilizará un vector de una dimensión que almacenará la cantidad de botellas producidas durante los 7 días de la semana.
El docente desarrolló la parte básica del sistema, pero el estudiante deberá completar varias funcionalidades adicionales para el análisis de datos.

## 2. Objetivos

### Objetivo General

Desarrollar un sistema capaz de gestionar y analizar la producción semanal utilizando JavaScript.

### Objetivos Específicos

- Aplicar el uso de vectores (arrays).
- Implementar funciones en JavaScript.
- Utilizar eventos mediante addEventListener.
- Aplicar estructuras repetitivas y condicionales.
- Mostrar resultados dinámicamente en la interfaz.


## 3. Funcionalidades del Sistema

El sistema permite realizar las siguientes operaciones:

- Cargar producción semanal.
- Presentar producción registrada.
- Calcular producción total semanal.
- Detectar mayor producción.
- Detectar menor producción.
- Calcular promedio semanal.
- Detectar producciones mayores al promedio.
- Detectar producción crítica.
- Verificar valores repetidos.
